# antislop audit 001: Home page

- Date: 2026-11-27
- Mode: AFTER (audit only, nothing changed yet)
- Scope: `src/app/page.tsx` (guest and logged-in views) and the components it renders: `DailyGoalCard`, `DailyTaskRow`, `PlantGrowth`, `ReviewMomentumCard`, `StudyRhythmCard`, plus `src/app/loading.tsx` and the shared CSS in `src/app/globals.css`.
- Priority follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Lock = LOW.
- Verification: findings come from reading the code and computing contrast ratios. The app was not run in a browser (R-35), because `.env` points at a remote Supabase database and the logged-in view needs a real account.

## HIGH (Hard Gate)

1. **Em dashes in UI text** (R-02). `src/app/page.tsx:526` ("đưa vào mục ôn tập — bạn không..."), `src/components/learning/DailyGoalCard.tsx:58` ("Mục tiêu đã đạt — nghỉ ngơi..."), `src/components/learning/PlantGrowth.tsx:143` ("chặng cuối — Kết trái"). Fix: use a comma, period or colon instead.

2. **Icon ligature text is read aloud by screen readers** (R-39). The page has 11 `material-symbols-outlined` spans but only 3 carry `aria-hidden`. Material Symbols draws icons from ligature text, so a screen reader reads "Tiếp tục: ... arrow_forward", "local_fire_department", "bolt", "check", "rule", "auto_stories". This affects the greeting CTA, "Xem cả kế hoạch", onboarding, register, roadmap, the track cards and `DailyTaskRow`. Fix: add `aria-hidden="true"` to decorative icons, ideally once in a small `<Icon>` component.

3. **"Đang học" badge fails contrast** (R-25). `DailyTaskRow.tsx:38`: gold `#a8691a` on `#fdf3e2` measures 4.06:1, below 4.5:1, at 9px. Fix: darken the text (for example to `#8a5a14`, the C2 colour) or use a different badge treatment.

4. **No error state for the home page** (R-27). There is a `loading.tsx` but no `error.tsx` or `global-error.tsx` under `src/app`. If the database query in `getOverview` or `getHomeMotivation` fails, the user gets the default Next.js error screen with no cause and no next step. Fix: add `src/app/error.tsx` that says loading failed and offers a retry (`reset()`) and a link to `/review`.

5. **Two different streak numbers for the same user** (R-38, C-5). `StudyRhythmCard` shows the live streak, which is 0 once a day is missed. `DailyGoalCard` (`page.tsx:206`) and the header badge (`HeaderBar.tsx`) show `user.streak` from the database, which only resets when the user comes back. Someone who stopped a week ago sees "0" in one card and "10 ngày" in another. Fix: compute the live streak in one helper and use it in all three places.

6. **No written design direction** (R-37). There is no `DESIGN.md`. The `mockups/` folder and the CSS tokens (green brand, sage background, gold accent) act as unwritten direction. Fix: write a short `DESIGN.md` with palette, typography reason, voice and the three dials, so later UI work has something to follow. A suggested Design Read, based on the current code: "Learning dashboard for Vietnamese IELTS learners, calm botanical language (plant growth motif), dial ENERGY 2 / RHYTHM 2 / MOTION 1."

## MEDIUM (Purpose-Gate)

7. **Pill badge above the guest H1** (R-09). `page.tsx:262`: the dot is gone, but the bordered, uppercase, shadowed pill "Lộ trình IELTS · A1 đến C2" is still the eyebrow-badge pattern. Fix: turn it into plain text like the logged-in `.eyebrow`, or work "IELTS A1 đến C2" into the subheadline.

8. **Arrow on almost every button and link** (R-08). `arrow_forward` appears on the greeting CTA, "Xem cả kế hoạch", "Bắt đầu thiết lập", "Bắt đầu học miễn phí", "Xem toàn bộ lộ trình", both track cards, every `DailyTaskRow` and "Ôn ngay". When every control has an arrow, it stops pointing anywhere. Fix: keep it on the one primary "continue" action per view (and maybe the task rows, where it signals "open"), and drop it elsewhere.

9. **Wide-tracked uppercase labels in every section** (R-06). `.eyebrow` (0.14em, uppercase) sits above every heading: "Kế hoạch", "Ôn tập", "Nhịp học", "Thiết lập lộ trình", "Nội dung", "Cấp độ". So do the 10px `tracking-[0.15em]` labels in the next-lesson card, track cards, `DailyTaskRow` and PlantGrowth ("toàn khoá học"). Several of them repeat the heading under them ("Cấp độ" over "Sáu chặng, một hành trình", "Nội dung" over "Chọn nội dung học"). Fix: keep eyebrows only where they add a fact the heading lacks (for example "Kế hoạch · A1 · Ngày 3/30"), and drop the rest.

10. **Blurred radial orb in the closing banner** (R-01). `page.tsx:517-520`: `bg-mint/20 blur-3xl` circle behind the brand banner, with no stated purpose. Fix: remove it, or replace it with something from the plant motif.

11. **Static lesson preview shows invented progress** (R-38, borderline). Guest hero preview (`page.tsx:317-370`) shows "Chuỗi 5 ngày" and "+20 XP". It is `aria-hidden` and clearly a product illustration, so it is not a statistic claim. Still, the values are made up. Fix (optional): use a real lesson's question and XP from the database, or drop the streak line.

## LOW (Quality Locks)

12. **Closing banner is a template section** (C-3, R-05). `page.tsx:515-531`: a full-width brand block that repeats what the guest hero and the plant section already say, with no action. Logged-in users see it on every visit. Fix: remove it, or show it only to guests with the register CTA.

13. **Guests see empty progress UI** (C-3). The Plant section ("Hạt giống", 0%), the track cards ("0/N bài đã hoàn thành", 0% bars) and the level cards (0%) render for logged-out visitors. Progress bars at zero tell a guest nothing. Fix: for guests, show what each section contains (lesson counts, topics) without progress bars, or show the plant as "how your tree grows" instead of "0%".

14. **Loading skeleton does not match the page** (R-27 quality, antislop-ui "Placeholder loading states"). `src/app/loading.tsx` draws a centered hero with three pill buttons. Neither the guest hero (two-column, left-aligned) nor the logged-in greeting looks like that, so the layout jumps when data arrives. Fix: shape the skeleton like the logged-in greeting plus the plan/goal grid.

15. **Inter chosen without a written reason** (R-06). `--font-sans` and `--font-display` are both Inter. Inter is valid (good Vietnamese diacritic support is a real reason), but the reason is not written down. Fix: record it in `DESIGN.md` (finding 6), or pick a display face that carries the botanical voice.

16. **Palette grows past 3 colours in the level cards** (R-29). `LEVEL_META` adds teal `#0e7490`, slate blue `#245a7a` and brown `#8a5a14` to the green, gold and red already in use. The colours do encode level, so this is a purpose question, not a ban. Fix: write the reason down, or step through shades of the green brand from A1 to C2.

17. **Day squares in `StudyRhythmCard` rely on `aria-label` on `<li>`** (R-39, minor). Screen readers do not reliably announce `aria-label` on a plain list item. Fix: put the label in visually hidden text inside each `<li>`.

## Checked and passing

- R-17 / R-36: the guest stats (levels, lessons, questions) and every logged-in number come from the database. No invented metrics.
- R-18 / R-28: no testimonials, no FAQ.
- R-24: every header link (`/daily`, `/roadmap`, `/grammar`, `/vocabulary`, `/vocabulary/learned`, `/reading`, `/writing`, `/review`) has a matching route.
- R-25: body text passes (muted on background 5.40:1, muted on surface-muted 5.14:1, brand on brand-soft 6.12:1, white/75 on brand 4.72:1, all level colours on white at least 5.36:1).
- R-32: a global `:focus-visible` outline exists in `globals.css`.
- R-39 motion: `prefers-reduced-motion` is handled globally.
- R-10 / R-13: no glassmorphism, no glow.
