## Nguyên tắc

- **IELTS Academic**, không phải General Training.
- A1–A2 là **pre-IELTS**; B1 mới bắt đầu format IELTS đầy đủ.
- Giải thích bằng tiếng Việt; bài đọc, câu hỏi, bài mẫu bằng tiếng Anh.
- Không copy audio/transcript có bản quyền.
- Mọi unit có mục tiêu, input, task, answer key/model, lỗi thường gặp và cách tự học.
